# whether weather

출사와 나들이 갈 곳을 고르기 위한 **전국 시·군·구 시간별 예보 지도**입니다.
기상청 단기예보를 3시간마다 받아 와서, 지역별 날씨와 출사 적합도를 지도 색으로 보여줍니다.

**바로 가기: https://kjso521.github.io/whether_weather/** (PC·모바일 모두 지원, 설치 불필요)

---

## 사용법

1. **시각 고르기** — 지도 아래 슬라이더를 움직이면 그 시각의 전국 상황으로 지도가 다시 칠해집니다. 오른쪽에 날짜와 시각이 표시됩니다.
2. **보고 싶은 항목 고르기** — 메뉴에서 출사 지수나 날씨 항목을 선택합니다. PC는 오른쪽 패널, 모바일은 오른쪽 위 ☰ 버튼입니다.
3. **지역 살펴보기** — 지도에서 지역을 누르면 그날의 시간별 예보(날씨, 기온, 강수확률, 습도, 풍속, 점수)가 나옵니다. 같은 지역을 다시 누르거나 지도의 빈 곳을 누르면 선택이 풀립니다. 지도는 끌어서 옮기고, 휠이나 두 손가락으로 확대할 수 있습니다.
4. **추천 지역 보기** — 출사 지수를 고르면 그 시각에 점수가 높은 지역 10곳이 순위로 나옵니다. 구는 도시 하나로 묶어 평균 점수로 보여주고(서울시, 대구시, 전주시 등), 누르면 그 도시에서 점수가 가장 높은 구가 선택됩니다.

## 볼 수 있는 항목

### 출사 지수 (0~100점)
지도에서 **보라색에 가까울수록 좋음, 분홍색에 가까울수록 나쁨**입니다. 회색은 그 시각이 해당 모드의 대상 시간대가 아니라는 뜻입니다.

| 모드 | 언제 | 무엇을 보나 |
|---|---|---|
| 나들이 | 항상 | 비 올 확률, 기온(20℃ 전후가 가장 좋음), 바람, 습도, 구름 |
| 일출·일몰 | 일출·일몰 전후 1시간 | 구름이 조금 있을 때 가장 높고, 흐리면 낮음 |
| 은하수 | 완전히 어두워진 밤 | 맑은 하늘, 달이 떠 있으면 감점, 습하면 감점 |
| 운해 | 일출 2시간 전 ~ 1시간 반 뒤 | 높은 습도, 약한 바람, 밤사이 기온이 크게 떨어짐, 위쪽 하늘 맑음 |

일출·일몰이나 은하수처럼 특정 시간대만 해당하는 모드를 고르면, 슬라이더가 가장 가까운 해당 시각으로 자동 이동합니다.

### 날씨
날씨(맑음/구름많음/흐림/비/눈), 강수확률, 기온, 풍속, 습도.

## 알아둘 점

* **예보 범위:** 오늘부터 약 4일 뒤까지입니다. 마지막 하루는 3시간 간격으로만 제공됩니다. 어제 시각도 남아 있으면 볼 수 있습니다.
* **갱신 주기:** 기상청 발표 시각(02·05·08·11·14·17·20·23시) 약 20분 뒤에 자동 갱신됩니다. 메뉴 맨 아래 "예보 발표" 시각으로 확인할 수 있습니다.
* **지수는 참고용입니다.** 예보의 하늘 상태가 3단계뿐이라 구름 양을 세밀하게 반영하지 못합니다. 은하수 점수에는 광공해(도시 불빛)가, 운해 점수에는 지형(고도)이 반영되지 않습니다. 미세먼지도 아직 없습니다.
* **지역 구분:** 시·군·구 250곳이며, 각 지역은 대표 지점 한 곳의 예보를 씁니다. 경계는 2018년 기준이라 이후 행정구역 변경은 반영되지 않았습니다.

## 직접 실행하기

설치할 것은 없습니다. Python 3만 있으면 됩니다.

```bash
python3 scripts/collect.py           # 예보 받기 (공공데이터포털 서비스 키 필요: .env 파일에 KMA_SERVICE_KEY=...)
python3 -m http.server 8000 -d web   # http://localhost:8000 에서 열기
```

서비스 키가 없으면 `python3 scripts/make_sample.py` 로 가짜 데이터를 만들어 화면만 볼 수 있습니다(실제 날씨 아님).

| 폴더 | 내용 |
|---|---|
| `web/` | 사이트 본체 (HTML/CSS/JS, 빌드 과정 없음) |
| `scripts/` | 기상청 예보 수집기 (Python 표준 라이브러리만 사용) |
| `tests/` | 테스트 (`python3 -m unittest discover -s tests`, `tests/js/run.sh`) |
| `.github/workflows/` | 예보 수집과 GitHub Pages 배포 자동화 |
